          Offhire & Repo utilization = trips ÷ daily trip target (default 30, editable above). Under the current schema 1 row = 1 trip (one truck run): a row carries Container A and, for a combo load, Container B — so a single row can move two containers but still counts as one trip. Container Moves counts A + B; Total Trips counts rows. Over 100% means the fleet ran harder than the daily target. Unique units count distinct NOPOL plates after normalizing case/spacing — the residual single-trip plates are likely occasional or mis-keyed trucks, so treat the core-unit count as the real fleet.
